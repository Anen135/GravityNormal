# Space Menu Assets

Этот архив содержит нарезку ассетов из концепта меню.

## Папки

- `Panels/`
  - `menu_panel_full.png` — вся левая sci-fi панель меню.
  - `menu_header_title.png` — заголовок `MAIN MENU`.
- `Buttons/`
  - `button_play.png`
  - `button_settings.png`
  - `button_exit.png`
- `Icons/`
  - `icon_play.png`
  - `icon_settings.png`
  - `icon_exit.png`
- `Backgrounds/`
  - `sun_large.png` — солнце / звезда.
  - `space_right_side.png` — правая часть сцены с солнцем.
  - `starfield_clean_top_right.png` — относительно чистый космический фон.
- `Reference/`
  - `full_menu_reference.png` — исходный концепт целиком.

## Важно

Это именно **нарезка из готового концепта**, а не вручную собранные прозрачные UI-элементы.
То есть у некоторых ассетов внутри кадра уже присутствует фон исходной сцены.

Если хочешь, следующим сообщением я могу сделать ещё 2 варианта:

1. **прозрачные UI-ассеты** (перерисованные отдельно: панель, кнопки, иконки),
2. **Unity-ready package** со структурой под `Assets/SpaceMenu/` и prefab builder-скриптом.
